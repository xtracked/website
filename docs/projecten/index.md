# Projecten

Iedere opdracht vertelt zijn eigen verhaal.

Van innovatieve consumentenproducten tot open standaarden voor digitale interoperabiliteit.

De onderstaande projecten laten zien hoe de [werkwijze](../werkwijze.md) van Xtracked in uiteenlopende contexten is
toegepast.

    integraties eenvoudiger maakt.

    [:material-arrow-right: Lees meer](./funql.md)

-   :material-connection:{ .lg .middle } &nbsp; **ZorgAPIs**

    ---

    Van strategie tot softwareontwikkeling.

    Het ZorgAPIs Platform laat zien hoe het zichtbaar maken van de samenhang tussen API's, standaarden en organisaties
